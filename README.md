# Rahamah Abdulkadir | Portfolio

A single-page portfolio with a photo viewer, local fonts and a static PDF download. It uses HTML, CSS and JavaScript and has no install or build step.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

## Deploy on Vercel

Push the **contents** of this directory to the GitHub repository root. Import that repository into Vercel and choose the **Other** framework preset. Keep the repository root as the project directory and leave the build command and output directory unset.

## Edit

Page copy and image descriptions are in `index.html`, the responsive layout and print styles are in `styles.css`, and the photo viewer and motion are in `portfolio.js`. Photos and fonts are in `assets/`. If you change the PDF, keep its existing filename so the download link continues to work.
